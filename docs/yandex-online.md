# Онлайн и Яндекс Игры

## Запуск и сборка

Node.js 22, `npm ci`. Для локальной разработки: `npm run server` (по умолчанию порт 8082) и `npm run dev` (порт 8083). Для телефона в той же Wi-Fi сети запустите `npm run dev -- --host` и откройте `http://IP-компьютера:8083`. WebSocket `/ws` автоматически проксируется на локальный сервер комнат; `PUBLIC_MULTIPLAYER_URL` позволяет явно переопределить адрес. При переопределении порта комнат через `PORT` передайте то же значение процессу `npm run dev`. `npm start` запускает исходники через Python; этот вариант ожидает сервер на порту 8082 (`npm run server`). Разработка использует явный SDK в памяти без настоящей рекламы и платежей.

Для портала задайте `PUBLIC_MULTIPLAYER_URL=wss://YOUR_DOMAIN/ws` и выполните `npm run build`. Загружается содержимое `build/`, с `index.html` в корне архива. SDK загружается из официального `/sdk.js`; скрытого перехода в тестовый режим нет. Без URL серверных комнат игра остаётся одиночной. `npm run build:demo` создаёт отдельный `build-demo/` с тестовым SDK; такой архив нельзя отправлять на модерацию.

Сервер хранит только присутствие, последние позы и парты. Одна карта seed42, автоматические комнаты до 20 человек, обновления 10 Гц, интерполяция 200 мс. Другие игроки не участвуют в коллизиях и экономике. Доступны бег/ходьба/прыжок, обучение, выбранный персонаж, машина и её движение, падение/телепорт. 20 парт выдаются атомарно сервером, освобождаются при выходе из класса и отключении. Во время рекламы, покупки и паузы место удерживается. После потери связи возможна одиночная игра; переподключение согласует место заново. Нет чата или взаимодействий между игроками.

Docker необязателен. Примеры установки без него и с ним: [deployment/README.md](../deployment/README.md). Шаблоны не установлены и не подтверждают доступность публичного WSS.

## Облачные данные

`player.getData/setData`, ключ `urbanRouteSave`: версия конверта 1, `updatedAt`, карьера, настройки языка/громкости и ранее заработанные права. Текущий рейс и положение не сохраняются. Первоначальное чтение обязательно: ошибка показывает повтор загрузки и не создаёт пустое сохранение поверх существующего. При временном сбое дальнейшие изменения остаются в памяти с индикатором «Не сохранено». Закрытие страницы может их потерять. Записи ограничены по частоте; повторные попытки с задержками.

При синхронизации сравнивается целый снимок: выигрывает более новый `updatedAt`, равенство отдаёт приоритет облаку. Права постоянных персонажей объединяются отдельно. Применение другого снимка перезагружает игру после успешной синхронизации. Это не объединение денежных операций. Смена аккаунта блокирует записи старого аккаунта и перезагружает игру.

Старые локальные данные читаются только при отсутствии облачной записи для однократного переноса. Игра больше не пишет в localStorage/IndexedDB и не создаёт локальные резервные сохранения. Подтверждённые постоянные покупки восстанавливаются через SDK; при недоступности списка покупок ранее сохранённые права не пропадают.

## Постоянные покупки

В Консоли Яндекс Игр включите покупки и создайте пять постоянных товаров. Готовые иконки PNG 256×256 и CSV для импорта перечислены в [README проекта](../README.md#инап-покупки-id-и-иконки):

| Персонаж | ID товара |
| --- | --- |
| Dancing NPC Girl | `skin_dancing-npc-girl` |
| Jandel | `skin_jandel` |
| KreekCraft | `skin_kreekcraft` |
| Spyder Sammy | `skin_spyder-sammy` |
| Spider-Man | `skin_spider-man` |

Целевое значение цены —39 в каталоге. Портальная валюта определяется SDK: интерфейс использует `IProduct.price` и `getPriceCurrencyImage('small')`, без жёсткой надписи «рубли». Фактическую цену и валюту проверьте в консоли и тестовом платеже: значение 39 в каталоге не является обещанием 39 рублей во всех регионах. [Документация каталога и валюты](https://yandex.ru/dev/games/doc/ru/sdk/sdk-purchases).

Персонажи покупаются навсегда, `consumePurchase` не вызывается. Игровые деньги не позволяют купить эти пять моделей. Ранее заработанное владение переносится. Результат платежа подтверждается SDK; долгий открытый платёжный диалог не обрывается общим сетевым тайм-аутом. Остальные персонажи сохраняют игровую экономику. Разрешение на коммерческое использование моделей заявлено пользователем; подтверждающие документы в репозитории не добавлялись, сведения об авторах и лицензиях сохранены.

## Реклама и паузы

Одна попытка после 240 секунд активной игры. Предупреждение 2→1 длится две секунды и останавливает управление, физику, заработок и звук. Скрытие вкладки, потеря фокуса или пауза SDK прерывают предупреждение: при возвращении оно начинается заново. Время в фоне не приближает показ. Сохраняется только одна ожидающая попытка, накопленной очереди нет. Закрытие, ошибка, отсутствие рекламы или отказ SDK сбрасывают интервал.

Показ откладывается на мосту/возле полного полотна и возле всей зоны движения препятствия. Запас от полного корпуса игрока/машины: max(50 м, модуль фактической скорости×5 с). Также откладывается во время прыжка, падения, загрузки, телепорта и открытых игровых окон. Реклама вызывается только через SDK. Все основания паузы учитываются независимо, поэтому закрытие рекламы не снимает паузу платформы.

## Проверка перед публикацией

`npm run test:online`, `npm run stress:online`, `npm run build`. Свежие измерения и ограничения: [qa/online-release/README.md](../qa/online-release/README.md). Общий исторический `npm test` имеет устаревшие ожидания; его статус описан отдельно в отчёте.

На реальном черновике проверьте Game Ready после готовой сцены, GameplayAPI, аккаунты, облако между устройствами, покупку/отмену/восстановление пяти товаров, рекламу/ошибку/офлайн, звук и паузу, доступность публичного WSS, RU/EN, реальные мобильные устройства и ориентации. [Методы SDK](https://yandex.ru/dev/games/doc/ru/requirements/1/19), [события паузы](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events), [сохранение прогресса](https://yandex.ru/dev/games/doc/ru/requirements/1/9). Эти проверки ещё не подтверждены; сборка не означает прохождение модерации.
