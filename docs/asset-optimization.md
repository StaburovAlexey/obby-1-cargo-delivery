## Модели и текстуры

- GLB перепакованы через glTF Transform: старые неиспользуемые BIN-изображения
  больше не переносятся, одинаковые текстуры и accessor объединяются.
- Meshopt хранит геометрию и анимационные буферы без численного округления.
  Позиции, нормали, UV, веса и клипы персонажей не упрощаются. Изменяется порядок
  хранения вершин/индексов, поэтому байтовые контракты оригиналов относятся к
  исходникам, а контрольные суммы runtime-копий записаны отдельно.
- Новые машины упрощаются консервативно с ограничением ошибки 0,03% радиуса и
  сохранением границ. Материалы колёс и проверенных фар защищены. Если меняется
  хотя бы один экстремум геометрии, соответствующее упрощение отменяется: масштаб
  и расположение колёс зависят от исходных габаритов. BMW E30 и Cadillac сохраняют
  исходное число треугольников; их файлы уменьшаются за счёт сжатия ресурсов.
- Koenigsegg: 42 879 → 38 335 треугольников. Phoenix: 26 501 → 21 440, включая
  удаление закрытых непрозрачными окнами салона и руля. Днище, подвеска, колёса
  и узлы ламп сохранены. При подготовке используется игровой алгоритм выделения
  колёс и стоп-сигналов, в том числе после декодирования конечного GLB.
- Цветовые карты используют KTX2 ETC1S quality 255. Нормали, карты параметров
  материалов и чувствительные карты стекла/ламп используют KTX2 UASTC с Zstd.
  Предел разрешения 1024×1024, меньшие изображения не увеличиваются; добавлены
  mipmap-уровни. Цветовые/emissive карты помечены sRGB, карты данных — linear.
- Общий загрузчик подключает Meshopt и KTX2. Basis JS/WASM поставляются локально,
  одновременно работают статический сервер и сборки с хешированными именами.
  Лимит транскодера — два worker. Лицензии включены в обе платформенные сборки.

Происхождение, размеры, настройки текстур и контрольные суммы каждого GLB:
[`art/optimized-models/manifest.json`](../art/optimized-models/manifest.json).
Перепаковка без изменения изображений отдельно убирает 3 679 492 байта из набора
персонажей; эта экономия уже включена в итоговую таблицу.

## Окружение и загрузка

Полная созданная процедурная геометрия четырёх корней сцены уменьшилась
с 252 395 до 163 753 треугольников (35,12%). Основная карта:
165 507 → 98 387 (40,55%). Это числа до отсечения невидимых объектов, без GLB
машин/персонажей, не число треугольников одного кадра. Подробности, исходные
снимки и совпадающие хеши коллизий:
[`procedural-geometry-optimization.md`](procedural-geometry-optimization.md).

Стартовая сцена начинается пешком и ждёт выбранного персонажа, шрифты и нужные
изображения. Витринные машины и персонажи загружаются очередями по близости.
Посадка и предпросмотр явно дожидаются нужной модели. Предвычисленные габариты
сохраняют коллизии припаркованных машин до появления визуальной модели.
Запросы отменяются при пересоздании мира; опоздавшие результаты освобождаются.
Изображения категорий магазина получают `src` только при первом открытии.

Дубли raw-копий картинок магазина/дыма исключены из платформенных сборок.
Исходные GLB и декодеры также не копируются вторым набором: нужные файлы
эмитируются сборщиком через литеральные URL. Музыка остаётся отложенной и
не участвует в ожидании первого запуска.

## Музыка и WebP

Музыка перекодирована из 256 в 128 кбит/с без обрезки, с исходным числом каналов
и частотой дискретизации. Число декодированных PCM-сэмплов сохранено для каждого
трека. Все расцветки остаются 1024×1024; изображения используют quality 85/88
с порогами дополнительного искажения RGB PSNR ≥37 dB, block SSIM ≥0,975.
Исходники не перекодируются повторно при следующем запуске утилиты.
Инструкции и ограничения: [`scripts/optimize-media.md`](../scripts/optimize-media.md).

## Повторная подготовка

Требуется `npm ci`, KTX-Software 4.4.2 с `toktx` и FFmpeg/FFprobe с libmp3lame.
Инструменты кодирования не включены в игру.

```sh
npm run prepare:model-decoders
npm run prepare:vehicle-bounds
TOKTX=/path/to/toktx npm run optimize:models
FFMPEG=/path/to/ffmpeg FFPROBE=/path/to/ffprobe npm run optimize:media
npm run build:all
```

Тесты и проверки в браузере по просьбе пользователя не запускались. Подготовка
ресурсов включает чтение конечных GLB и подсчёт их данных; это не игровая
проверка. Визуальное качество KTX2 и процедурных материалов, прослушивание MP3,
время холодного запуска, потребление памяти и FPS на Android не измерены.
Известные устаревшие числовые ожидания существующих тестов перечислены в отчёте
процедурной геометрии; сами тесты оставлены без изменений.

Финальный `npm run build:all` завершился с кодом 0 для обеих платформ.
Содержимое `build/` занимает 56 172 502 байта, `build-vk/` — 57 025 060 байт
до ZIP/HTTP-сжатия. В каждой сборке 32 GLB (31 производная модель и исходный
Jeff), одна точная копия Basis WASM и один JS-wrapper с сохранённой фабрикой
`BASIS`. Одинаковых файлов GLB/WebP/WASM внутри каждой сборки не обнаружено.
`git diff --check` завершился без замечаний. Проверка кода отдельным агентом
не выявила подтверждённых блокирующих проблем. Это состояние до создания коммита.
