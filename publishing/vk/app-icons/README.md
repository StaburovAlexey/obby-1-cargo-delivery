# Иконки «Обби: доставка груза» для VK

Готовые PNG для полей на скриншоте:

| Поле | Файл | Размер |
| --- | --- | --- |
| Универсальная иконка | `icon-universal-576.png` | 576 × 576 px |
| Иконка для каталога и сниппетов | `icon-catalog-278.png` | 278 × 278 px |
| Маленькая иконка | `icon-small-150.png` | 150 × 150 px |
| Фавикон | `favicon-32.png` | 32 × 32 px |

Все файлы — квадратные PNG с непрозрачным фоном, без надписей и заранее скруглённых углов. Для фавикона создана отдельная композиция без персонажа и окружения.

Архив для передачи: `../app-icons-upload.zip`. В архив входят только четыре готовых PNG.

Исходные изображения сохранены в `masters/`. Генерация выполнена встроенным инструментом `image_gen`; точные промпты и ссылки на референсы записаны в `generation-prompts.json`. Размеры подготовлены с помощью Sharp и фильтра Lanczos3.

## Анимированная иконка экрана запуска

В поле «Анимированная иконка» загрузите `loading-icon-96.json`.

- Формат: Lottie JSON, 96 × 96 px.
- Размер файла: 21 926 байт, меньше 24 КБ даже при лимите в 24 000 байт.
- Цикл: 2 секунды, 30 кадров/с.
- Движение: разметка уходит назад относительно машины; колёса вращаются вперёд со скоростью, согласованной с дорогой. Кузов и посылка слегка покачиваются.
- Колёса вписаны в арки, имеют толщину шин, шестиспицевые диски и перспективу боковой плоскости кузова.
- Композиция полностью векторная, без внешних изображений, шрифтов и других ресурсов.
- Превью: `loading-icon-preview.gif`; обновлённая копия для просмотра без кэша — `loading-icon-preview-v2.gif`. В VK загружается JSON.

Анимация создана отдельно в цветах статичных иконок. Исходник: `build-loading-icon.mjs`. Повторная сборка из корня проекта:

```bash
node publishing/vk/app-icons/build-loading-icon.mjs
```

В Chrome с lottie-web 5.13.0 проверены SVG- и Canvas-рендереры, воспроизведение полного цикла, отсутствие ошибок и совпадение начального и конечного состояния. Результат локальной проверки: `output/playwright/vk-loading-icon/verification.json` от корня проекта.

Описание формата: [Lottie shape layers](https://lottiefiles.github.io/lottie-docs/layers/), [Lottie shapes](https://lottiefiles.github.io/lottie-docs/shapes/). Проигрыватель для локальной проверки: [airbnb/lottie-web](https://github.com/airbnb/lottie-web).
