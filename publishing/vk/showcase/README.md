# Изображения «Обби: доставка груза» для VK

| Поле в настройках VK | Файл | Размер |
| --- | --- | --- |
| Большой сниппет | `snippet-1120x630.png` | 1120 × 630 px |
| Скриншот 1: ангар с машинами | `screenshot-01-garage-600x1200.png` | 600 × 1200 px |
| Скриншот 2: городской маршрут | `screenshot-02-city-600x1200.png` | 600 × 1200 px |
| Скриншот 3: снежный маршрут | `screenshot-03-snow-600x1200.png` | 600 × 1200 px |

В разделе скриншотов оставьте ориентацию «Книжная», как на предоставленном скриншоте настроек. Все четыре файла — PNG.

Архив `../showcase-upload.zip` содержит только четыре готовых PNG для загрузки.

Сниппет сгенерирован встроенным `image_gen` в стиле ранее созданной иконки. Исходник сохранён в `masters/snippet.png`, точный промпт — в `generation-prompts.json`.

Скриншоты сняты из настоящей локальной игры в Chrome через Playwright, в окне 600 × 1200 px. Для съёмки подготовлены позиции персонажа, машины и камеры; интерфейс и сцены отображаются самой игрой. Локальный SDK хранит состояние съёмки в памяти. Финальные скриншоты копируются из браузера без растягивания и кадрирования.

Отчёты съёмки и контрольные кадры находятся в `output/playwright/vk-showcase/` от корня проекта. Итоговые размеры и контрольные суммы перечислены в `files.json` рядом с этим документом.
