# Urban Route · Three.js

Конечный локальный игровой прототип: маршрут доставки через пять биомов, ангар с десятью покупаемыми машинами и наградным BMW, 17 персонажей, 20 парт и пять учебных входов. Окружение создаётся кодом. Десять автомобилей используют предоставленные модели Cosmo (CC0), по две на биом; наградной BMW использует отдельную импортированную модель. Старые процедурные автомобили и городской грузовик удалены. До загрузки GLB автомобиль не имеет резервной геометрии. Персонажи — предоставленные пользователем GLB без крыльев. Добавлены комнаты до 20 игроков и интеграция постоянных покупок через SDK Яндекс Игр. Публичный сервер и товары в консоли настраиваются отдельно.

## Онлайн и Яндекс Игры

Две независимые сборки из общего кода: `npm run build:yandex` → `build/`, `npm run build:vk` → `build-vk/`, `npm run build:all` → обе. Настройка SDK, сохранений, рекламы и сервера покупок VK: [docs/platform-builds.md](docs/platform-builds.md). `npm run build` сохраняет Яндекс основной платформой.

Актуальная настройка: [docs/yandex-online.md](docs/yandex-online.md). Автоподбор комнаты до 20 человек, только отображение поведения; парты резервируются сервером. Карта фиксирована, seed 42. Сохранения и настройки — в облаке SDK. Последние пять персонажей — постоянные покупки; цена и значок валюты берутся из каталога. Реклама запрашивается после четырёх минут активной игры с предупреждением «3, 2, 1» и откладывается возле мостов и препятствий. Интерфейс сохраняет RU/EN; автоматический выбор использует язык SDK.

Сборка для портала: `PUBLIC_MULTIPLAYER_URL=wss://YOUR_DOMAIN/ws npm run build`; результат в `build/`. Без URL комнаты отключены. Локальная сборка с явным SDK в памяти: `npm run build:demo`. Сервер можно запустить без Docker; [шаблоны systemd/nginx и Docker](deployment/README.md). Результаты текущей проверки: [qa/online-release/README.md](qa/online-release/README.md).

## Запуск

`npm ci`, затем `npm run dev` и `npm run server` в двух терминалах. Локальный SDK работает в памяти; покупок за реальные деньги и настоящих рекламных показов в этом режиме нет. Нужны Node.js 22 и браузер с WebGL 2. `npm start` оставлен для запуска исходников через Python 3. Для хостинга достаточно содержимого `dist/`. Three.js, иконки и модели включены; CDN не требуется. Открытие через `file://` не поддерживает загрузку ES-модулей/GLB.

Для разработки и production-сборки через Rsbuild (Rspack) нужен Node.js 20.19+ или 22.12+:

```bash
npm ci
npm run dev
```

`npm run dev` открывает сервер разработки на `http://127.0.0.1:8080`. Для сборки и проверки готовой версии:

```bash
npm run build
npm run preview
```

На хостинг загружается содержимое `build/`. Сборка минифицирует JavaScript/CSS, обрабатывает ссылки на GLB и копирует звуки, иконки и лицензии. Пути относительные, поэтому сборку можно разместить в подкаталоге сайта. Исходники остаются в `dist/`; эта папка не очищается сборщиком. `npm start` по-прежнему запускает исходную версию без сборки. Серверы используют один порт, поэтому запускайте их по одному.

## Модели автомобилей

Город: coupe и police. Лес: jeep и van. Пустыня: kamaro и ghini. Снег: rally и armor. Вулкан: lamb и fenyr. Внутренние ID, покупки, улучшения и характеристики сохранены. Цвета кузовов подобраны под биомы без перекраски стекла, шин и фар.

Модели увеличены в 1,5 раза и имеют одинаковые пропорции в ангаре и на дороге относительно героя ростом 3,5 м. Колёса, дорожная опора, столкновения и частицы используют увеличенные размеры. Визуальная коробка на крыше скрыта; загрузка груза и награды продолжают работать.

Модели сохраняют пропорции; все четыре колеса вращаются и поворачиваются отдельно. Посадка на дорогу и опора на мосту учитывают фактические колёса. Это устраняет раннее падение узких машин по старой ширине грузовика. Динамика разгона и управления не менялась. На гараж приходится 23 207 треугольников и 109 примитивов импортированных машин, без груза и теней. GLB загружаются локально по два одновременно, суммарный размер 1,75 МБ. Лицензия и сведения: [Cosmo](dist/assets/vehicles/cosmo/README.md).

## Текущая дорога

Ориентир контрольной чистой поездки последней машины с максимумом — до 12 минут. Это не гарантия времени любого игрока. Ускорение машины ради сокращения поездки не менялось.


- Около 15 869 м по трёхмерной центральной линии. Порядок: город → лес → пустыня → снег → вулкан.
- Ширина дороги 30 м, 26 плавных поворотов (семь в городе), заметные подъёмы и спуски. Первый поворот начинается через 80 м. Четыре развилки с разными высотными профилями соединяются обратно; направление выбирается рулём.
- 16 пар остановок. Слева по направлению от старта — выгрузка, справа — заправка.
- 25 узких мостов: по 5 на биом, ширина 5 м, длина 24 м, разные смещения поперёк дороги. Под боковыми разрывами нет невидимой полной дороги. При потере опоры машина наклоняется, соскальзывает и возвращается в ангар без награды.
- 30 детерминированных препятствий: 20 движущихся (по четыре на биом) и 10 неподвижных. Каждый движущийся объект проходит 21,2 м поперёк дороги за 8 секунд, ждёт 1,4 секунды и возвращается за 8 секунд. Минимальный промежуток между встречами в проверенном расположении — 180 м; плотной непрерывной цепочки нет. Вулканические камни остаются неподвижными. Свободный проход выбирается по текущему положению препятствия, постоянного обхода за всей зоной движения нет.
- Новые препятствия распределены вне мостов, остановок и въездов на развилки. Движение использует ограниченные общие пулы и приостанавливается вместе с игрой.
- Единая квадратная LEGO-текстура остаётся на всех покрытиях; биом меняет цвет, сцепление, сопротивление и частицы. Мелких геометрических пупырышек нет.
- Дома непрерывными рядами, высота ×2, модуль фасада около 18 м (×3 первоначальной ширины), магазины на первом этаже. Соседние корпуса используют общие срезы на поворотах; текстуры метрические.

Погода плавно смешивается на протяжении 180 м вокруг границы биомов (90 м до и после). Частицы, дымка и цвет неба/тумана используют общую плавную смену; телепорт и возобновление не включают полную бурю одним кадром. В обычном биоме рисуется один пул 768 частиц, при переходе максимум два. В ангаре погода выключена.

В ангаре верхние кнопки идут одной вертикальной колонкой слева. Подтверждение покупки машины, персонажа и обучения показывает «Купить» и стоимость; подробности и цены над объектами сохраняются.

## Управление и рейс

Пешком: экранный джойстик или WASD. Справа прыжок, на компьютере Space. Свайп/мышь вращает камеру. Проём ангара открыт, но пешком выйти на трассу нельзя. Подойдите к купленной машине: персонаж сядет, машина перенесётся на свободный старт, загрузится один груз. Руль и D/R перенесены из разрешённого проекта tow-confiscator; удержание руля даёт газ. Переключение направления сначала тормозит до остановки. Управление восстановлено из Site34: дополнительного автоторможения и помощи в развороте нет, прежний накат сохранён.

За рулём камера после 6 м настоящего движения плавно возвращается. На месте таймера возврата нет. Защита от стен отключена. «Обзор» ставит поездку на паузу и показывает текущую сеть; верхний «Ангар» отменяет рейс. Выходить из автомобиля на дороге нельзя.

Выгрузка один раз начисляет указанную сумму и возвращает пешком в ангар. Заправка заполняет текущую ёмкость бака и сохраняет груз. Пустой бак и ручной возврат дают нулевую награду. Расход идёт по фактическому пути, включая задний ход и занос; на месте не расходуется. У каждой стабильной точки фиксированная награда: круги и повторные касания её не увеличивают.

Кнопка «Биом» — тестовый переход текущей машины. Она сбрасывает движение/ввод/частицы, не тратит топливо за телепорт и отключает оплачиваемую доставку до нового рейса из ангара.

## Деньги, мозги, покупки

Первая машина и Bacon бесплатны. Остальные покупки требуют явной кнопки и достаточного баланса. Владение сохраняется. Над закрытыми машинами/скинами только значок денег и цена; у купленных ценник скрыт.

Фактическое движение даёт 3 мозга/с. Пять учебных входов дают 1,5 / 1,8 / 2,2 / 2,6 / 3 мозга/с только сидя. Первый бесплатный, доступ к остальным стоит 1000 / 4000 / 12000 / 30000 игровых денег. Любой класс можно купить напрямую; предыдущие классы не требуются. Любой вход выбирает первое свободное место из общих 20; ставка определяется входом. Парты одного стиля, 5×4. Встать можно кнопкой или движением; персонаж возвращается к классу. При скрытой вкладке дохода нет.

За мозги улучшаются скорость, управление, сцепление и объём бака конкретной машины. У каждого параметра десять уровней: первые три характеристики по +1%, бак по +3% за уровень. Цена уровня L для машины N: round5(40 × 1,35^(L−1) × 1,2^(N−1)). Покупка бака увеличивает максимум, но не выдаёт текущее топливо. Цены десяти машин: 0 / 1300 / 3200 / 6500 / 10000 / 16000 / 25000 / 45000 / 78000 / 100000. Пропуск машин разрешён.

Чистый рейс даёт +20% денег и +4% мозгов от базовой выплаты; полностью пройденная сложная main/ridge-ветка — +15% и +4%. Первая доставка в каждую точку даёт +5% денег и +1% мозгов один раз. Небольшие миссии можно пропускать без награды; в ангаре можно выбрать денежную цель на машину. Все бонусы оплачиваются только при успешной доставке. [Точные правила и исходный бюджет](qa/economy-seven-hour/proposal-ru.md). Его прежние 7 ч 58 мин рассчитаны до расширения мостов и больше не описывают текущую сложность. После утверждения компактной карты дальность машин скорректирована, а цены и все 16 выплат сохранены. Новый бюджет карьеры рассчитывается отдельно; прежняя длительность не обещается. Это моделирование, не среднее по человеческим плейтестам.

Одноразовая тестовая кнопка «Деньги на все машины» добавляет ровно дефицит цены ещё не купленных машин с учётом кошелька. На новой карьере это 285 000. Выдача учитывается отдельно от заработка; она доступна только в явном локальном режиме разработчика и исключена из расчёта обычного темпа. Это не реальные деньги.

Справа сверху кошелёк и мозги. Внизу одна строка: топливный бар с канистрой и `текущее/максимум` слева, скорость справа. Пять учебных значков привязаны к своим мировым точкам; при боковом взгляде естественно перекрываются по глубине.

Контрольные поездки через производственную физику: последняя машина с максимумом около 10:31; только с баком 10 и остальными параметрами 0 — около 11:25. На машинах 7, 8 и 9 первое улучшение бака открывает разные следующие выгрузки. Это результаты проверочного водителя, а не замер среднего игрока.

## Сохранение и техническая основа

Единственное постоянное хранилище текущей игры — `player.getData/setData` SDK Яндекс Игр, ключ `urbanRouteSave`. Старый `urban-route-career-v1` читается один раз при создании облачного сохранения для переноса прогресса; новых локальных записей нет. Сохраняются деньги, мозги, покупки машин/скинов/классов, улучшения, выбранный персонаж, завершённые доставки, первые награды, текущая миссия и цель на машину. Прежние покупки/ID не менялись. Положение, груз и незавершённый рейс не сохраняются. При ошибке начального чтения игра предлагает повторить загрузку и не перезаписывает облако пустым прогрессом. После загрузки сбои синхронизации оставляют изменения в памяти до закрытия страницы. При конфликте выбирается целое сохранение с более новым `updatedAt` (при равенстве — облако); постоянные права на персонажей объединяются. Комнатный сервер не хранит экономику. Подробности: [PROGRESSION.md](PROGRESSION.md).

Физика — собственное плоское твёрдое тело с силами в четырёх точках колёс и шагом 1/120 с. Высота и наклон берутся с тех же треугольников, которые рисуют дорогу. История ребра графа общая для кузова/колёс, чтобы соседняя ветка не перехватывала выбор поверхности. Полный корпус ограничен объединённым дорожным коридором; скорость вдоль края сохраняется. Это не полная подвеска или физика прыжков автомобиля. У остановок ровные площадки; уклоны и повороты проверяются отдельно от длины маршрута. Подробности физики и точечного отката: [PHYSICS.md](PHYSICS.md).

## Проверки

- `npm run test:weather-transitions`: плавные переходы, покрытие камеры, падение/ангар и покупка/интерфейс.
- `npm run test:compact-route`: целевая проверка компактной карты, препятствий, сохранений, наград и интерфейса.
- `npm run test:career-retention`: содержит историческую бюджетную модель прежней карты; её длительность не является текущей оценкой.
- `npm test`: исторический общий набор; часть его ожиданий относится к прежним ценам/ставкам и трём уровням. Зелёный общий прогон текущего выпуска не заявлен.
- `npm run test:hills`: плавные холмы и независимый аудит.
- `npm run test:rollback`: точное совпадение управления с Site34 и короткие проезды склонов.
- `npm run test:network`: граф, визуальная геометрия, препятствия, независимый аудит и настоящие рейсы через физику.
- `npm run test:upgraded-routes`: десять машин с максимальными улучшениями по обеим веткам.
- `npm run test:study-clock`: доход при разных частотах кадров и скрытии вкладки.

В выпуске Site35 сеть была проверена 70 рейсами производственной физики, 25 механическими сценариями и 5 рейсами через настоящий цикл приложения с имитацией DOM/рендерера. Во время рейса тестовый контроллер меняет только газ и руль. Все 11 выплат, промежуточные заправки, пустой бак, обе ветки и конец после последнего поворота проверены. Дополнительно прошли 200 изолированных проездов всех машин по новым холмам; если участок длиннее бака слабой машины, это проверка динамики с измерением спроса на топливо, а не полный игровой рейс. Подробные результаты: `qa/route-hills/driving.json`, `qa/network-journeys/`, `qa/network-independent/`, `qa/network-hazards/`.

После отката управления сохранены исходные физические проверки и общий регрессионный набор. Текущие результаты: `qa/handling-rollback/` и `qa/handling-rollback-regression/`.

Диагностический кадр `qa/network-scene/geometry-montage.png` построен офлайн из экспортированных Three.js-вершин. Браузер, WebGL, GPU/FPS и реальные Android-жесты здесь не проверялись. Числа треугольников и batches — обход графа сцены, не замер GPU.

## Обновление поворотов и препятствий

Проверки: `npm run test:turns-crossings`. Контрольный чистый проезд последней машины с максимальными улучшениями: 716,6 секунды (11:56,6), все 25 мостов и 15 предварительных заправок. Водитель в тесте объезжает движущиеся препятствия примерно на 14 м/с; осторожный вариант на 8 м/с занял 13:58. Это офлайн-проверки настоящей физики и событий игры, а не замер игрока, браузера или GPU.

## BMW completion reward

An eleventh vehicle, BMW G80 M3, is earned only by a valid continuous route from the garage spawn through the final successful delivery. Debug travel, invalid teleports, failed or empty runs do not unlock it. Existing cars and currency remain unchanged. Old saves without explicit completion proof are retained but do not infer this new unlock from money, car ownership or historical checkpoint flags.

The reward uses the supplied real model by SharkyStudios, CC BY 4.0; source, license and modifications are documented in `dist/assets/vehicles/bmw/README.md`. Its body is gold metallic with a small local reflection environment; glass and tires retain source materials. A rotating forward-tilted garage pedestal sits beyond the existing car row. The reward has its own throttle-dependent rear-tire drift tuning: lift the accelerator to regain rear grip. No heading or turn-assist forces are added. The original ten cars retain identical dynamics.

Checkered finish paint and flags stand 28 route metres before the final unload point. Focused verification: `npm run test:reward-bmw`; real GLB/Three.js geometry and app mock-DOM tests, not a GPU or Android performance claim.

Developer preview: append `?dev=1` to the site URL. The BMW is available immediately for that session, and career persistence is disabled for the entire preview. Normal saved ownership, money and upgrades are read but never changed by this preview. Remove the query and reload to return to the regular completion lock.

The biome preview menu also offers “Перед финишем”: a safe road spawn 55 metres before the checker line. Like other previews this removes payable cargo and cannot grant the legitimate BMW completion unlock.

## Settings help and stable fuel readout

Settings now include RU/EN “How to play” instructions and an icon/control guide with 23 examples reused from the actual HUD. It explains choosing an unloading stop versus continuing, free refueling, cargo loss and collision bonuses, currencies, school, vehicle-specific upgrades, missions and the golden BMW reward. Developer-only controls are not presented as normal gameplay controls. Section shortcuts scroll only the modal; focus trapping, Escape/backdrop dismissal, pause and saved language/volume behavior are preserved.

The fuel bar displays whole numbers in separate, fixed-width current/capacity slots. Presentation rounds upward with floating-point tolerance; a positive remainder never displays zero, and a full tank has matching whole-number labels. Raw fuel values, upgraded capacities, usage, low-fuel thresholds and progressbar values retain their fractional precision. The canister, slash and maximum stay fixed as the remaining value crosses digit boundaries.
