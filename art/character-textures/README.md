## Происхождение и контракты

Изображения созданы встроенным `image_gen` по исходным атласам; перед встраиванием приведены к размерам финальных PNG, указанным в [manifest.json](manifest.json). Полный набор запросов генерации хранится в `prompts.json`.

`manifest.json` — сведения о происхождении и конечном результате. Для каждой модели записаны исходный и финальный SHA256 GLB, финальный размер, SHA256 геометрического контракта и длина/SHA256 исходного BIN-префикса. Для каждой карты записаны слот, имя PNG, размеры, финальный SHA256 и, когда карта уже существовала, SHA256 исходного изображения.

Геометрический контракт охватывает `meshes`, `accessors`, `skins`, `animations`, `nodes` и `scenes`. Контракт BIN-префикса сохраняет исходные байты, в том числе данные UV, вершин, весов, скелета и клипов. Утилита дописывает новые PNG и `bufferView`, переназначает изображения и сохраняет весь прежний BIN-префикс, включая старые неиспользуемые изображения. Для ранее нетекстурированных материалов она добавляет карты через явное сопоставление материалов. Форматирование JSON и общий размер GLB могут измениться.

## Повторная замена

Утилита [replace-character-textures.mjs](../../scripts/replace-character-textures.mjs) принимает отдельный CLI-манифест для одного GLB. **Этот `manifest.json` с происхождением файлов не является CLI-манифестом и не передаётся утилите напрямую.** Используйте исходный GLB выбранной модели и её собственные атласы; UV разных персонажей не взаимозаменяемы. Для выполнения требуется Node.js 22+.

Пример CLI-манифеста, сохранённого в корне проекта как `bacon-textures.json`:

```json
{
  "input": "original-bacon.glb",
  "output": "/tmp/bacon-retextured.glb",
  "images": {
    "0": "art/character-textures/bacon-0.png"
  }
}
```

Для исходного нетекстурированного Spider-Man используется явное сопоставление материалов:

```json
{
  "input": "original-spider-man.glb",
  "output": "/tmp/spider-man-retextured.glb",
  "materials": {
    "0": {
      "png": "art/character-textures/spider-man-material-0.png",
      "baseColorFactor": [1, 1, 1, 1]
    },
    "1": {
      "png": "art/character-textures/spider-man-material-1.png",
      "baseColorFactor": [1, 1, 1, 1]
    }
  }
}
```

```bash
node scripts/replace-character-textures.mjs bacon-textures.json
```

Пути разрешаются относительно расположения CLI-манифеста. `images` заменяет встроенные изображения по индексу; `materials` добавляет карты только материалам без существующей `baseColorTexture` и проверяет наличие UV0. Для дальнейшей замены уже текстурированного Spider-Man используйте `images`. После изменения игровых GLB обновляются их контрольные суммы и размеры в каталоге/метаданных, а также данные происхождения и проверки конечного набора.

## Проверка и просмотр

```bash
npm run test:character-textures
```

Команда включает проверки утилиты замены, всех конечных встроенных PNG и контрактов сохранения, а также загрузки и размещения персонажей. Инструкция не означает, что команда уже выполнена; актуальный результат определяется её выводом.

Для визуального просмотра запустите локальную раздачу корня проекта и откройте `/qa/character-retexture/?group=0&view=front`. `group=0`, `1`, `2` выбирает группу моделей, `view=front` или `back` — сторону просмотра. Страница использует реальные GLB и игровой загрузчик. Это отдельный визуальный просмотр, а не подтверждение производительности и игрового поведения на устройствах.

Исторические результаты проверки первоначального экспорта от 12 октября сохранены в [README исходной коллекции](../../dist/assets/characters/README.txt) и отделены там от изменений текстур 15 октября.
