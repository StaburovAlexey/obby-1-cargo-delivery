# Карта и рейтинг комнаты на доске

На физической доске класса слева показаны основной маршрут и каньон с разными масштабами, справа — лучшие подтверждённые результаты присутствующих игроков. Бирюзовые точки показывают других игроков; собственная точка и подпись скрыты на обеих картах. Подписи используют стабильные номера игроков комнаты. Рейтинг показывает первые десять мест; личный результат ниже десятого места занимает последнюю видимую строку с настоящим номером места.

Доска размером 28 × 9 м закреплена на передней стене класса: её задняя грань совпадает с внутренней поверхностью стены, Canvas расположен на лицевой стороне рамки. Центр доски находится на высоте 6,75 м. Область обновления привязана к классу и не смещается при переносе доски.

Деревянные рейки и полка используют тот же материал и цвет, что мебель класса. Матовая поверхность карты участвует в освещении и тональном преобразовании сцены; бирюзовая основа, кремовые подписи, синие и золотые акценты согласованы с палитрой игры. Поверхность отнесена от подложки на 7 см, оставаясь за лицевой гранью рамы. Для уменьшения мерцания вдали используются mipmaps и анизотропная фильтрация до 4×. Статичное оформление рисуется один раз при смене языка.

Позиции, состав комнаты и результаты поступают из WebSocket-снимков. Точки используют интерполяцию с задержкой 200 мс; при телепорте, смене комнаты и возвращении к классу история сбрасывается. Canvas обновляется не чаще 15 раз в секунду, только в пределах 55 м от класса и только при изменении содержимого. В скрытой вкладке цикл игры не рисует доску.

Результат вычисляет существующий серверный проверяющий дрифта. Более слабый заезд не заменяет лучший; равные очки сортируются по меньшему времени, затем номеру игрока. Выход игрока удаляет его результат из рейтинга. Это временные результаты текущих соединений; глобальная таблица Яндекса работает отдельно.

## Автоматические проверки

```sh
npm run test:classroom-board
npm run test:online
npm run build:yandex
```

## Проверка в браузере

Запустите `npm run server` и `npm run dev`. Войдите в бесплатный класс через первый вход. На доске видна карта без собственной точки. Второй браузер должен попасть в ту же комнату; его движение отображается бирюзовой точкой. При движении только местного игрока карта не перерисовывается, если остальные данные комнаты неизменны. Личный результат по-прежнему выделяется в рейтинге.

Для повторяемой локальной проверки сначала освободите место в классе, затем запустите:

```sh
node qa/classroom-board/room-peers.mjs
```

Два клиента займут первые свободные стулья, третий проедет каньон примерно за 41 секунду с реальной проверкой движения сервером. После финиша его результат появится на доске. Ctrl+C отключает клиентов и удаляет их точки и результаты.

Для проверки полного холста отдельно от 3D-камеры запустите из корня репозитория `python3 -m http.server 8766 --bind 127.0.0.1`, откройте `http://127.0.0.1:8766/qa/classroom-board/`. Страница использует производственный модуль доски и настоящий сервер комнаты. Кнопка «Вдали от класса» останавливает изменение счётчика обновлений текстуры, «Рядом с классом» возвращает актуальный состав комнаты. «Подготовить PNG» позволяет сохранить полный холст. QA-страница не входит в сборку игры.

При выпуске обновите клиентскую сборку и `server/room-server.mjs` вместе. Старый сервер продолжит передавать позиции, но не пришлёт рейтинг комнаты. Публичный сервер в рамках этой доработки не развёртывается.
